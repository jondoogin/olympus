# Image-generation direction

Each image was produced independently, with no logos or website layouts baked into the scene. The mood-board reference was used loosely for its marble/sky/editorial world rather than copied as a composite.

Global exclusions for every prompt: no text, logo, watermark, border, presentation board, collage, or multiple panels. Photorealistic material detail and sophisticated museum-catalog × contemporary fashion-editorial quality.
