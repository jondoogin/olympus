# S22 — Installable iPhone PWA (Claude)

- Added manifest (stable id `/`, scope `/`, standalone, shortcuts), hand-written service worker (no new dependencies), branded offline page, iOS/Android meta, full-bleed icon set from the struck-O master.
- Safe areas: `--safe-top`, `--safe-bottom`, `--header-bar`; `--header-h` includes the top inset so every hero offset follows automatically.
- AppShell: SW registration (checks for updates on foreground), offline/online notice, install invitation, share button on case studies (Web Share, clipboard fallback).
- Verified in headless Chromium: build, `npm run check` (84 pages, 20 interactions), `npm run check:pwa` (manifest, icon sizes, opaque apple icon, SW activated and controlling, offline cached page + offline fallback, iOS invite open/dismiss/persist, hidden in standalone, no overflow at iPhone 15 Pro width, no console errors).
