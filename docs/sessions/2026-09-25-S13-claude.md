# S13 — Route pages, page turns, brief form, CI, touch motion

Branch `claude/next-features-chatgpt-wait-btk862`, built on `main` after S12 (PR #5).

- **Route pages + 404 + SEO:** `src/lib/meta.ts` holds per-route title/description/og image (App tab titles use it too). `scripts/site-plugin.ts` writes `dist/<route>.html`, `404.html` (noindex), `robots.txt`, `sitemap.xml` (when `VITE_SITE_URL` is set) and a modulepreload for each route's chunk. `vercel.json` now uses `cleanUrls` with no catch-all rewrite, so unknown URLs return 404. Project og:images are 1.91:1 crops made by `npm run images` (`SOCIAL` in build-images.mjs → `_responsive/social/`).
- **Deploy size:** the plugin removes master PNGs that only feed `npm run images` from `dist` (79 MB → 23 MB). Nothing in `public/` changed.
- **Code split:** non-home pages are lazy (`src/routes.tsx`), preloaded when idle. Honest gain is ~5 KB gz; React and site.ts dominate.
- **Page turns:** `components/PageTransitions.tsx` intercepts internal link clicks, loads the route, swaps it inside `document.startViewTransition`. Card image → case lead image morph via `view-transition-name: case-media`. Styles at the end of components.css.
- **Contact brief form:** `sections/ContactForm.tsx`, copy in `contactForm` (site.ts). Mail-draft by default; `VITE_CONTACT_ENDPOINT` switches to JSON POST. Honeypot field, inline errors, focus management.
- **Mobile/tablet motion:** `hooks/useFocusBand.ts` + "Touch focus", "Lightning" and "Scroll-linked type" blocks in sections.css. Desktop unchanged.
- **CI:** `.github/workflows/ci.yml` runs build + `npm run check` (scripts/check-site.mjs: every route × 4 widths for overflow, broken images, overlay, console/HTTP errors; plus services keyboard, reduced-motion film, card navigation at 1440/390, mobile menu, contact brief, header ink on direct HELIO load). Failure screenshots upload as an artifact.
- Found and fixed a regression from lazy loading: the header read its ink before a lazily loaded page mounted (HELIO direct load showed dark ink on dark). Now re-probes on `#main` child changes; covered by the check.
- Verified: `npm run build`, `npm run check` all clear; visual passes at 390 / 768 / 1440; slowed-down captures of the page turn and card morph; mutation test (injected overflow) made the check fail as expected.
- Not done: Work filters (still only four projects, per ROUTES.md). Not tested on a physical device or in Safari; scroll-timeline effects need Safari 26+/Chrome 115+ and are simply absent elsewhere.
