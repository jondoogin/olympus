# S13 — Reactive OLYMPUS logo

The owner wanted the bolt-through-O mark to convey movement and respond to people. The supplied SVG remains the source of truth. `Logo.tsx` adds a class to the O path and wraps the existing gold bolt path in a group, preserving its built-in SVG transform. The shared component now responds to pointer position, keyboard focus, and pointer down. CSS adds a brief idle strike and a tap strike; the reduced-motion rule disables all new movement.

Verification: `npm run build` passed. The local browser showed all three logo instances, no error overlay or console errors, and keyboard focus visibly moved the O and bolt. Chrome responsive inspection reported `scrollWidth === innerWidth` at 390, 768, 1024, and 1440 px. The motion still needs owner review on a physical phone and desktop before the local branch is published.
