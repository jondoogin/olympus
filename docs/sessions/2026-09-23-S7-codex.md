# S7 — VELA media

- Added three generated VELA masters: a fabric close-up, a second campaign composition, and a material/identity still life. The existing fashion campaign image was used as visual direction; no existing master was edited.
- Ran `npm run images`, which added responsive JPEG/WebP derivatives and image-manifest keys for the new masters.
- Built a silent 9-second H.264 motion study from the three stills with `scripts/build-vela-film.sh`. The film is a moving editorial montage of stills, not filmed footage or generated character motion. Output: `public/media/vela-motion-study.mp4` (about 1 MB).
- Integrated the stills and film into `/work/vela`. The page uses a still instead of mounting the video when `prefers-reduced-motion: reduce` matches, and listens for preference changes.
- `npm run build` passed. Browser review at 1440, 1024, 768 and 390 px found no horizontal overflow. Mobile gallery layout and desktop film frame looked sound; the browser reported the film playing with no media error. Reduced-motion rendering was not visually verified.
- A local ffmpeg binary came from Python's `imageio_ffmpeg` package. To regenerate where `ffmpeg` is not on PATH, set `FFMPEG_BIN` to the binary path before running `bash scripts/build-vela-film.sh`.
